動画を見ながら操作を覚えたいときは、お手本を画面の隅に置いて、自分のアプリで同じ手順を試せます。

## 使い始めるには

1. macOS 14 以降に対応しています。`.dmg` をダウンロードして開き、Fuwa を「アプリケーション」フォルダにドラッグします。
2. Fuwa を開き、案内に従って画面収録を許可します。ウインドウの映像は Mac 内でのみ処理されます。
3. 固定したいウインドウを手前に出し、`⌥⌘P` を押します。解除するには、固定した映像にポインタを合わせ、もう一度同じキーを押します。

## 表示位置と大きさを変える

初期設定では映像が元のウインドウに追従し、映像越しに背後のアプリをクリックできます。動画を画面の隅に置くには、Fuwa のウインドウ一覧で歯車をクリックし、「独立した参考ウィンドウ」を選びます。好きな位置に移動して大きさを変えたり、見たい部分だけを選んで表示したりできます。
