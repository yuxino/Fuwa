跟著影片教學操作時，可以把示範畫面放在螢幕一角，邊看邊在自己的 App 裡練習。

## 開始使用

1. Fuwa 適用於 macOS 14 或以上版本。下載並打開 `.dmg`，再將 Fuwa 拖入「應用程式」資料夾。
2. 打開 Fuwa，依提示允許螢幕錄製。視窗畫面只在這台 Mac 上處理。
3. 切換到想固定的視窗，按下 `⌥⌘P`。要取消固定，將游標移到置頂畫面上，再按一次快捷鍵。

## 調整置頂畫面

預設情況下，畫面會跟隨原視窗，你可以直接點選下方的內容。若想把教學畫面放到一角，點選 Fuwa 視窗列表中的齒輪，選擇「獨立參考視窗」。你可以拖曳視窗、調整大小，也可以只框選想看的部分。
