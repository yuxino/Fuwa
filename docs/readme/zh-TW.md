## 置頂方式

- **跟隨原視窗**　畫面會隨原視窗移動和縮放，滑鼠仍可直接點選下方的內容。
- **獨立參考視窗**　從視窗列表的齒輪選單開啟後，可以單獨移動畫面、調整大小，或只顯示選取的區域。

## 安裝與使用

1. [下載 Fuwa](https://github.com/yuxino/fuwa/releases/latest)，打開 `.dmg`，將 Fuwa 拖入「應用程式」。需要 macOS 14 或以上版本。
2. 首次固定視窗時，依提示允許螢幕錄製。視窗畫面只在這台 Mac 上處理。
3. 切換到要固定的視窗，按下 `⌥⌘P`。將游標移到固定的畫面上，再按一次即可取消固定。
