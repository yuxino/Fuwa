## 表示モード

- **元のウィンドウに追従**　元のウインドウに合わせて映像の位置とサイズが変わります。映像越しに背後のアプリをクリックできます。
- **独立した参考ウィンドウ**　Fuwa のウインドウ一覧で歯車をクリックして切り替えます。映像を好きな位置に移動したり、サイズを変えたり、選択した範囲だけを表示したりできます。

## インストールと使い方

1. [Fuwa をダウンロード](https://github.com/yuxino/fuwa/releases/latest)し、`.dmg` を開いて Fuwa を「アプリケーション」フォルダにドラッグします。macOS 14 以降が必要です。
2. 初めてウインドウを固定するときは、案内に従って画面収録を許可します。映像は Mac 内でのみ処理されます。
3. 固定したいウインドウを手前に出して `⌥⌘P` を押します。解除するには、固定した映像にポインタを合わせてもう一度押します。
