照着视频教程操作时，可以把示范画面放在屏幕一角，一边看，一边在自己的应用里跟着做。

## 开始使用

1. Fuwa 适用于 macOS 14 或更高版本。下载并打开 `.dmg`，把 Fuwa 拖入「应用程序」文件夹。
2. 打开 Fuwa，按提示允许屏幕录制。窗口画面只在本机处理。
3. 切到想固定的窗口，按 `⌥⌘P` 置顶。要取消，把鼠标移到置顶画面上，再按一次。

## 调整置顶画面

默认情况下，画面跟随原窗口，鼠标可以直接点击下方的内容。如果想把教程单独放在一角，点击 Fuwa 窗口列表里的齿轮，选择「独立参考窗」。你可以拖动它、调整大小，也可以只框选想看的部分。
