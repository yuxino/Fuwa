## 창 표시 방식

- **원래 창 따라가기** 모드에서는 고정한 화면이 원래 창의 위치와 크기를 따라갑니다. 화면 아래의 앱도 그대로 클릭할 수 있습니다.
- **독립 참고 창** 모드에서는 화면을 따로 옮기거나 크기를 조절하고, 원하는 영역만 골라 표시할 수 있습니다. Fuwa의 창 목록에서 톱니바퀴를 눌러 이 모드를 선택하세요.

## 설치 및 사용

1. [Fuwa를 다운로드](https://github.com/yuxino/fuwa/releases/latest)한 뒤 `.dmg` 파일을 열고 Fuwa를 응용 프로그램 폴더로 드래그하세요. macOS 14 이상이 필요합니다.
2. 처음 창을 고정할 때 안내에 따라 화면 기록을 허용하세요. 창 화면은 사용 중인 Mac에서만 처리됩니다.
3. 고정할 창을 맨 앞으로 가져와 `⌥⌘P`를 누르세요. 해제하려면 고정된 화면 위에 포인터를 놓고 같은 단축키를 다시 누르세요.
