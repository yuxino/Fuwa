## 置顶方式

- **跟随原窗口**　画面随原窗口移动和缩放，鼠标可以直接点击下方的内容。
- **独立参考窗**　从窗口列表的齿轮菜单开启后，可以单独移动画面、调整大小，或只显示选中的区域。

## 安装与使用

1. [下载 Fuwa](https://github.com/yuxino/fuwa/releases/latest)，打开 `.dmg`，将 Fuwa 拖入「应用程序」。需要 macOS 14 或更高版本。
2. 首次置顶时，按提示允许屏幕录制。窗口画面仅在本机处理。
3. 切到要置顶的窗口，按 `⌥⌘P`。将指针移到置顶画面上，再按一次即可取消。
